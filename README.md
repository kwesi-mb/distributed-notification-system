# Distributed Notification System

A production-style microservices notification platform built with FastAPI.

## Services

- API Gateway
- User Service
- Template Service
- Email Service
- Push Service

## Tech Stack

- FastAPI
- PostgreSQL
- RabbitMQ
- Redis
- Docker
- SQLAlchemy
- Alembic

## Architecture

Event-driven microservices using RabbitMQ for asynchronous communication.
